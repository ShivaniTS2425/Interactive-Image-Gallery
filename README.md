Beauty Of Nature is a simple and responsive interactive image gallery built using HTML, CSS, and JavaScript.
The project displays nature images in a grid layout and allows users to click on any image to view it in a larger lightbox (popup) view with a smooth animation and an easy-to-use close button.

This project is ideal for beginners learning frontend development, image galleries, and basic DOM manipulation.

Features

* Responsive image grid using CSS Grid

* Click any image to open it in lightbox view

* Fixed close (×) button at the top-right corner

* Smooth hover effects and fade-in animation
  
* Mobile-friendly and responsive design

* No external libraries required

* Technologies Used

* HTML5 – Structure of the webpage

* CSS3 – Styling, layout, and animations

* JavaScript – Image click handling and lightbox functionality
